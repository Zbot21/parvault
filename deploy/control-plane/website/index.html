Zero-Trust Erasure-Coded Backup Daemon & Library

parvault is a statically-linked Linux backup utility and embedded Rust library that backs up directories across your own machines, a dedicated homelab server (parvault-seed), or an untrusted peer-to-peer mesh—without monthly storage fees or trusting remote hosts.

  • Encrypt-Before-Shard (Post-Quantum): Every 16 MiB stripe is sealed client-side with a 512-bit cascaded key (ChaCha20-Poly1305 → AES-256-GCM) plus NIST FIPS 203 ML-KEM-768 and FIPS 204 ML-DSA-65 before erasure coding.
  • GF(28) Reed-Solomon Erasure Coding: Splits ciphertext into N shards where any K reconstruct the file (2-of-3 personal ring, 10-of-20 probationary pool, 16-of-20 earned high-uptime homelab pool at 80% efficiency).
  • 4-Layer Blinded Shards: Remote disks store only opaque .bshard files keyed by HMAC-SHA256 blinded locators. Even 20 colluding storage nodes face a 2224.8 combinatorial wall and cannot identify which shards belong to the same file or user.
  • Bounded Footprint: Single static musl binary (0 dynamic libc dependencies) with a < 32 MiB RAM ceiling (3.52 MiB measured RSS), suitable for OpenWrt/prplOS routers, Raspberry Pis, and NAS boxes.

1. CLI Quickstart: parvault vs. parvault-seed man parvault(1)

The project ships two binaries from the same codebase: run parvault on machines with folders you want backed up, and run parvault-seed on headless storage boxes (NAS, Raspberry Pi, or cloud bootstrap nodes) that hold encrypted shards for other machines without holding any decryption keys or plaintext of their own. 

# A. Back up a local directory on your laptop or workstation:
parvault watch-folder \
  --folder ~/Documents \
  --snapshot-out ~/Documents.manifest.bin \
  --interval-secs 30

# B. Restore the directory tree onto a fresh machine:
parvault restore-folder \
  --snapshot ~/Documents.manifest.bin \
  --out-dir ~/Documents-Restored
# C. Run a 24/7 Homelab Redundancy Vault on your NAS / Raspberry Pi
#    (0-quota cost for your own devices; earns 16-of-20 Homelab tier):
parvault-seed start \
  --mode homelab-vault \
  --data-dir /mnt/nas/parvault-seed \
  --max-gb 500

# D. Run a zero-knowledge Public Bootstrap Seed Anchor:
parvault-seed start \
  --mode public-bootstrap \
  --data-dir /var/lib/parvault-seed \
  --max-gb 200
