Zero-Trust Erasure-Coded Backup Daemon & Library

parvault is a statically-linked Linux backup utility and embedded Rust library that backs up directories across your own machines, an OpenWrt / prplOS gateway router, a dedicated homelab server (parvault-seed), or an untrusted peer-to-peer mesh—without monthly storage fees or trusting remote hosts.

  • Zero-IP Auto-Discovery & 4-Word Pairing: Home LAN nodes and routers auto-discover via signed UDP beacons (port 4009). Pair devices in seconds with a 4-word BIP-39 code (parvault pair / parvault join)—zero IP addresses to type.
  • Router-SoC Profile (1 MiB Stripes): With --profile router-soc, transient memory peaks at 9.72 MiB VmHWM inside a 32–48 MiB cgroup, enabling turnkey Cloud-NAS appliances on OpenWrt and prplOS gateway routers.
  • Encrypt-Before-Shard (Post-Quantum): Sealed client-side with a 512-bit cascaded key (ChaCha20-Poly1305 → AES-256-GCM) plus NIST FIPS 203 ML-KEM-768 and FIPS 204 ML-DSA-65 before erasure coding.
  • GF(28) Reed-Solomon Erasure Coding: Splits ciphertext into N shards where any K reconstruct the file (2-of-3 personal ring, 10-of-20 probationary pool, 16-of-20 earned high-uptime homelab pool at 80% efficiency).
  • 4-Layer Blinded Shards: Remote disks store only opaque .bshard files keyed by HMAC-SHA256 blinded locators (≥ 2224.8 combinatorial wall).
  • Zero-IP Online WAN Rendezvous: Peers discover each other across cities and dynamic ISP IPs via STUN-over-Noise address reflection and blinded rendezvous mailboxes.

1. CLI Quickstart: Zero-IP Home Setup (parvault init, up, discover, pair) man parvault(1)

In v0.4.0, you never need to type or look up IP addresses on your home LAN or router NAS. Initialize with a 24-word recovery phrase, turn on appliance mode with parvault up, auto-discover peers via signed beacons, and pair laptops with a 4-word code. 

# A. Initialize fresh keys & 24-word BIP-39 mnemonic:
parvault init --profile router-soc --watch /mnt/usb-nas/shared

# B. Turnkey Router Cloud-NAS appliance mode:
parvault up \
  --profile router-soc \
  --folder /mnt/usb-nas/shared \
  --status-http 0.0.0.0:4080 \
  --pair

# C. Auto-discover LAN nodes (Zero-IP!):
parvault discover
# D. Pair laptop to router with 4-word code:
parvault join --code shield-copper-alpine-matrix

# E. Back up & sync folders (zero IP flags needed!):
parvault watch-folder \
  --folder ~/Documents \
  --snapshot-out ~/Documents.manifest.bin \
  --interval-secs 30

# F. Restore files from LAN router:
parvault restore-folder \
  --snapshot ~/Documents.manifest.bin \
  --out-dir ~/Documents-Restored
